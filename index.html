CareSync

Quality-gated ELT platform for weekly clinic reporting

caresync.html — Python · dbt · Snowflake · GitHub Actions

A quality-gated ELT platform that turns unreliable weekly clinic file deliveries into a trusted Snowflake reporting database. A Google Drive sensor classifies every file on-time/missing/too-early/late against a 1-hour SLA window, pandas pre-validation checks schema and types before anything loads, and a SHA-256 content hash makes every load idempotent without TRUNCATE. A dependency-aware orchestrator cascade-skips downstream files when an upstream one is quarantined, and the failing file is physically quarantined with an immediate alert, not just a line in the end-of-run summary. dbt builds a 12-model star schema (6 staging + 4 dimensions + 2 facts) with 38 generic tests, PHI minimized by omission at the staging boundary. An independent post-validation layer re-verifies table population and 3 business reconciliation queries.
